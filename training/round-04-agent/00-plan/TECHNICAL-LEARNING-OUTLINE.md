## 5. 한글·영어·공식 약어와 설명·재현 확인

처음 등장한 용어는 **한글명(English Full Name, 공식 약어)** 형태로 익힙니다. 별도 약어가 없는 경우 **없음**으로 표기합니다.

| 한글명 | 영어 원명 | 공식·통용 약어 | 쉬운 뜻 |
|---|---|---|---|
| **키** | Key | 없음 | 값을 찾기 위한 식별 이름 |
| **값** | Value | 없음 | 해당 키에 연결해 저장하는 데이터 |
| **유효 기간** | Time To Live | TTL | 저장 항목이 유지되는 시간 제한 |
| **해시 테이블** | Hash Table | 없음 | 키를 바탕으로 빠른 조회를 돕는 자료구조 |

**자기 설명:** 키-값(Key-Value)은 이름표(키)로 대응하는 정보(값)를 찾는 저장 방식입니다. 없는 키를 조회했을 때의 결과도 설계해야 합니다.

**종이 재현(실행하지 않음)**
1. 사용자가 키 example을 조회한다고 가정.
2. 저장소에서 키와 연결된 값을 찾음.
3. 값이 있으면 반환, 없으면 미존재 표시.

**놓치기 쉬운 점:** 키가 항상 존재하거나 값의 수명이 무한하다고 가정하면 안 됩니다.

**내가 이해했는지 확인:** (1) 핵심 용어의 한글·영어를 설명할 수 있는가? (2) 입력→처리→예상 결과를 자료 없이 재구성할 수 있는가? (3) 아직 실행을 검증하지 않았다는 사실을 구별할 수 있는가?

**상태:** 교육용 원리 설명·예상답만 추가했습니다. 실제 신규 코드·개발 실행·학생 L4/L5 독립 재현은 **NOT_STARTED / NOT_VERIFIED**입니다. [처음으로 돌아가기](README.md).
